# 📦 Guts Trac

A full-stack product inventory manager. A **FastAPI + PostgreSQL** REST API powers a clean **React** UI where you can add, edit, delete, search, and sort products.

## ✨ Features

- Full **CRUD** for products (create, read, update, delete)
- **Live search** by ID, name, or description
- **Click-to-sort** columns (ID, name, price, quantity)
- Auto-dismissing success / error messages
- Auto-created database tables and seed data on first run
- **CORS** configured for the React dev server
- Interactive API docs at `/docs` (Swagger UI), generated by FastAPI

## 🛠️ Tech Stack

|-----------|---------------------------------------------|
| Backend   | Python, FastAPI, Pydantic, SQLAlchemy       |

## 🚀 Getting Started

### Prerequisites

- Python 3.9+
- Node.js 16+ and npm
- PostgreSQL running locally

### 1. Database

Create a PostgreSQL database:

```sql
CREATE DATABASE guts;
```

Then create a `.env` file inside `backend/` (copy from `.env.example`) and add your own credentials:

```env
DATABASE_URL=postgresql://<user>:<password>@localhost:5432/guts
```

### 2. Backend

```bash
cd backend
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install fastapi uvicorn sqlalchemy psycopg2-binary pydantic python-dotenv
uvicorn main:app --reload
```

The API runs at **http://localhost:8000** and the docs at **http://localhost:8000/docs**.

### 3. Frontend

```bash
cd frontend
npm install
npm start
```

The app runs at **http://localhost:3000**.

## 🔌 API Endpoints

| Method | Endpoint          | Description            |
|--------|-------------------|------------------------|
| GET    | `/`               | Welcome message        |
| GET    | `/products`       | Get all products       |
| GET    | `/products/{id}`  | Get a product by ID    |
| POST   | `/products`       | Add a new product      |
| PUT    | `/products/{id}`  | Update a product       |
| DELETE | `/products/{id}`  | Delete a product       |

### Product object

```json
{
  "id": 1,
  "name": "iPhone",
  "description": "Budget phone",
  "price": 99.0,
  "quantity": 10
}
```
